# Movies Recaps Tool
A single-file prototype UI for the requested Movies Recaps Tool.

Included:
- Video upload and 10-minute validation
- Gemini Burmese recap workflow placeholder
- Thiha / Nilar voice selector
- Voice Character presets
- 16:9 / 9:16 / 1:1
- Logo upload, size and circle style controls
- Source text/subtitle blur control
- Burmese auto subtitle toggle
- Audio/video auto-sync toggle
- Export pipeline UI

Important: real Gemini, Microsoft Edge TTS and FFmpeg processing require a backend and API/service configuration. This package is a working front-end prototype, not a deployed public service.
